# Qwen3.5-9B 拼接训练 BF16 数值可接受性

2026-11-10 · 4×A800 80GB · 作业 `181411`、`181412`、`181413`。三项作业完成，耗时分别为 4 分 6 秒、15 分 53 秒和 19 分 49 秒。实测源码提交 `ed71e6357f40765010502e9a210f825c91f1f7eb`。固定 181229 的已保存轨迹与 step 0 权重，所有作业 optimizer.step=0。

## 决策

**建议采用原版 BF16 拼接，保留严格原生前缀分段。** A 的短轨迹非劣检验通过，拼接到 FP32 的梯度距离为逐调用的 1.012 倍。B 的 FP32 门控补丁在长轨迹上使两路差异变大。既有 BF16 拼接差异也低于本次同题分半观察到的采样变异量级。

A 的全 FP32 参考覆盖两条短轨迹。B 覆盖 8 条长短轨迹，但其两路对照均使用 BF16 主执行路径。分半只有一个固定切分。长轨迹的绝对 FP32 误差和实际学习曲线仍无测量。建议适用于下一次独立受控更新，本次诊断保留原训练配置。

## A · 全 FP32 参考

选择长度为 1,023 和 7,825 token 的两条轨迹，共 2,147 个动作。按长度、非零优势和至少有一次精确前缀延伸选择，四次调用在拼接路径形成两条片段。四路共享同一动作掩码、优势、全批动作分母和 FP32 逐调用的 old log-prob。FP32 参考关闭 TF32，使用 Transformers 的 PyTorch Gated DeltaNet 递推、卷积和门控归一化，以及 eager attention。实际观测了嵌入、线性层、解码器和 Gated DeltaNet 的 FP32 激活。

| 路径 | 前向评分（秒） | 前反向（秒） | 对 FP32 逐调用的动作 log-prob 平均 / P99 / 最大绝对差 |
| --- | ---: | ---: | ---: |
| 全 FP32 逐调用 | 9.24 | 38.48 | 参考 |
| 全 FP32 拼接 | 8.46 | 40.38 | 1.637e-6 / 2.289e-5 / 5.341e-5 |
| BF16 逐调用 | 9.22 | 3.56 | 0.013143 / 0.104520 / 0.190987 |
| BF16 拼接 | 1.06 | 3.20 | 0.012797 / 0.099329 / 0.190987 |

非劣判据为拼接的相对 L2 ≤ 逐调用的 1.2 倍。实测 **1.012 ≤ 1.2**。

## B · 门控投影 FP32

沿用此前相同 8 条子集，44,162 个动作，76 次调用，15 个严格原生片段。两条路径在 24 个线性注意力层共修改 48 个模块，分别是 `layers.<i>.linear_attn.in_proj_a` 和 `layers.<i>.linear_attn.in_proj_b`。完整实际模块名见测量 JSON。两种小投影用 IEEE FP32 乘法，a 保持 FP32 进入衰减计算，b 在 sigmoid 前转回输入 BF16，保持 beta 与 FLA 原 dtype。其余 QKV、`in_proj_z` 和投影照常用 BF16。各组共享原 BF16 逐调用的 old log-prob 及同一固定分母。

| 拼接 vs 逐调用 | 动作 log-prob 均值 | P99 | 最大 |
| --- | ---: | ---: | ---: |
| 原 BF16 | 0.002689 | 0.080882 | 0.247631 |
| 两路 FP32 门控 | 0.005889 | 0.107243 | 0.358465 |

| 路径 | 前反向（秒） | 评分 + 前反向（秒） | 峰值分配（GiB） | 峰值预留（GiB） |
| --- | ---: | ---: | ---: | ---: |
| 逐调用 BF16 | 256.03 | 316.40 | 53.934 | 78.318 |
| 拼接 BF16 | 79.57 | 96.20 | 53.934 | 78.322 |
| 逐调用 + FP32 门控 | 258.37 | 318.07 | 54.416 | 78.334 |
| 拼接 + FP32 门控 | 79.67 | 96.56 | 54.416 | 78.322 |

峰值取前反向期间四个 rank 的最大 PyTorch 值，逐卡原值见 JSON。门控补丁使两路峰值分配均增加约 0.482 GiB。前反向耗时变化为逐调用 +2.34 秒、拼接 +0.10 秒。这是单次配对计时。补丁使两路差异从 29.56% 升到 58.16%；逐调用本身加入补丁后，与其原 BF16 梯度也相差 65.34%。B 的结果表明局部投影精度改善不能直接推出全模型梯度更接近参考。

## 参照 · 同题固定分半

固定种子 20261110 抽取 3 个完整查询组，每组 8 条已保存轨迹，组内随机分成 4+4。两半各 12 条、题目相同、轨迹无交集。沿用已保存奖励，分别在各半的同题组重算优势，各半用自己的全批动作数作分母。两半用同一 step 0 BF16 逐调用路径。
