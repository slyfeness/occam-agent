# Qwen3.5-9B 拼接训练梯度差异诊断

**结论**：旧对照的两种执行路径使用同一轨迹级分母。统一为整批动作 token 求和后，拼接与逐调用的全参梯度仍相差 29.55%，高于 1.08% 的重复噪声底。匹配输入的消融把首个可复现分歧定位到第一层 Gated DeltaNet 的 BF16 门值投影。拼接保留为诊断候选，实际更新路径继续采用逐调用。

## 样本与版本

主对照从作业 `181229` 的 128 条已判分轨迹中选取 8 条。按最长原生序列长度和是否有分词分歧分层，各取 4 条，未使用奖励筛选。最短与最长实际输入分别为 787 和 56,166 token。保存的优势直接使用。两路共享同一份初始 step 0 权重，44,162 个动作及其掩码，PPO clip=0.2，统一采用逐调用的 step 0 log-prob 作为 old log-prob。

诊断逐调用核对拼接序列的原生因果前缀、动作位置及保存的采样概率。工具观察保留在上下文中，直接损失掩码为零。历史四处分词分歧从 `180554` 和 `181174` 的保存批次独立回放。三个诊断作业均无 optimizer.step。

## 2. 损失归约和全参梯度

旧代码对每条轨迹的动作损失求和，再除以该轨迹动作数及轨迹总数。旧逐调用与旧拼接使用相同公式。新对照两路都把所有动作损失相加，除以固定的 44,162。另测逐调用内部 token 平均后按 76 次调用等权平均。

| 比较 | 梯度相对 L2 | 余弦 |
| --- | ---: | ---: |
| 逐调用，全批统一分母，同输入重复 | 1.08% | 0.999942 |
| 拼接 vs 逐调用，全批统一分母 | **29.55%** | **0.956010** |
| 仅改归约，逐调用内部平均 vs 全批统一分母 | 260.46% | 0.937374 |
| 仅改归约，旧轨迹均值 vs 全批统一分母 | 174.14% | 0.936180 |
| 拼接 vs 逐调用，两路均用旧轨迹均值 | **36.41%** | **0.932762** |

相对 L2 也反映梯度尺度变化，余弦刻画方向。两种归约确实会改变目标，但旧实验两路归约相同。36.41% 与 29.55% 的差值不能解释成归约贡献的可加分解。

## 3. 固定上游梯度和算子定位

- **相同因果前缀与上游梯度。** 远离分歧的实测例把序列从 21,136 延长到 28,250 token，固定 17 个相同动作位置、相同 LM Head 分块及其上游梯度。log-prob 最大绝对差复现为 0.247631，前反向分别为 7.09 和 9.07 秒，全参梯度相对 L2 为 44.39%，余弦为 0.897634。该结果属于定位出的单例。
- **第一层 BF16 门值投影。** 共同输入逐位一致。独立执行 `in_proj_a` 时，BF16 的整个共同前缀投影最大差为 0.0625，衰减门最大差为 0.006861，17 个动作对应位置的门值最大差为 7.77e-5。固定投影前缀后门值差为零。仅用 IEEE FP32 重算该投影时，整个前缀门值最大差降至 7.15e-7，动作位置最大差降至 2.98e-7。该局部精度对照用时 7.32 秒。
- **FLA。** 将逐位相同的原生前缀 q/k/v、衰减门和 beta 送入同一个 FLA chunk 算子，短长两次的探针输出和五种输入梯度在实测中相同，新增未来位置梯度为零。这个控制隔离了序列长度在首层 FLA 算子内部的影响。
- **Transformer 梯度检查点。** 对 652 → 4,096 token 的独立实测，开启与关闭时，短长梯度相对 L2 分别为 6.78% 和 6.73%。相同短输入开关检查点只相差 0.56%。四次前反向共约 4.17 秒。LM Head 的重计算设置保持一致。
- **FSDP 分片。** 用真实首层输入和同一初始权重，在 2,048 / 4,096 token 上分别比较第一层 mixer 的 `FULL_SHARD` 和 `NO_SHARD`。同长度的输出逐位一致，梯度相对 L2 分别为 2.40e-10 和 3.49e-10。两种分片方式的短长梯度相对 L2 均为 1.45e-4。该控制覆盖首层 mixer，耗时 156.09 秒，含模块加载和对照计算。整模型仍按原四卡 FSDP 路径测试。

结论适用于已测试的 BF16 执行路径。首层门值投影是已复现的最早分歧点，单层 IEEE FP32 对照尚未验证全模型梯度能恢复到重复噪声底，因此保留现有逐调用正式路径。
