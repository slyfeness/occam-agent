组均值先对每条轨迹的动作 token 求平均，再对组内轨迹等权平均。16 条逐轨迹变化全部符合各自优势的方向。更新前两遍训练侧重评分的 56,025 个 token 差值全部为 0。零优势对照的梯度范数为 0，AdamW 执行后四个 rank 的参数哈希均与初始值一致。对照的 AdamW 状态独立丢弃后执行真实更新，裁剪前梯度范数为 1.47824454，四个 rank 的可训练分片均有参数变化。weight decay 和 KL 均为 0，未加载 Reference。

PPO 分母采用更新前训练引擎重算的 old log-prob。真实 vLLM 采样 log-prob 仅作诊断，两条数值路径逐动作 token 的绝对差为均值 0.01019895、p99 0.12452133、最大值 1.26424241。

可训练文本参数共 8,953,803,264，视觉编码器冻结且从优化器排除。实际 FSDP wrap 类是 `Qwen3_5DecoderLayer`，训练开启梯度检查点。每个 rank 实际调用 `fla.ops.gated_delta_rule.chunk` 9,216 次，recurrent 路径调用为 0。训练使用 FP32 主权重、FP32 Adam 状态、BF16 前向和 FP32 梯度归约，动作位置用完整词表分块归一化。

GPU 分项为同一阶段各 rank 时间区间的并集，各阶段可能有跨 rank 重叠。CPU 指标是进程树 RSS 之和的采样峰值，可能重复计算共享页面。训练期四卡 NVML 采样峰值依次为 79.20、79.22、79.20、79.18 GiB。生成和 32B 判分缺少覆盖整个阶段的 GPU 采样，完整显存峰值未知。

180554 的 rollout 全阶段可拆为检索服务就绪 148.71 秒、双 Actor 并行启动至就绪 365.55 秒、就绪后到最后一条轨迹结束 526.96 秒、收尾 13.34 秒。依据为控制器 `PHASES.json`、各服务 `ready.json` 和 `ROLLOUT_COMPLETE.json` 的时间戳。就绪后的 526.96 秒包含 worker 启动、生成、检索和轨迹记录，双卡端到端吞吐约 106.3 个输出 token/s。

两台 vLLM 的最后一份请求指标合计 189 次请求、3,927,002 个输入 token（包含逐轮重送的历史）和 56,025 个输出 token。每请求平均排队 0.12 秒、prefill 2.30 秒、decode 16.56 秒。请求间并发重叠，这些平均值用于定位瓶颈。推理阶段每个 Actor 实际最多同时处理 8 个请求，倒数第二条轨迹结束后仍有 139 秒的单轨迹尾部。服务沿用了历史自然 rollout 的 BF16 TP1、eager、关闭 prefix cache 配置，CUDA Graphs 和编译处于关闭状态。固定长度历史测速的加速倍率需要在真实多轮负载中重新测量。

检查点保存了 Actor、Adam 和 CPU/CUDA RNG。人为扰动参数后重载，同一批 56,025 个动作 log-prob 的最大绝对差为 0，每次调用最后一个动作位置的完整词表 logits 最大绝对差也为 0。

180621 的第一次真实 step 和更新后评分完成，但 PyTorch 的 LOCAL_STATE_DICT CPU 卸载路径在保存时因 requires_grad 元数据冲突终止。180647 的小模型预检又发现 LOCAL_STATE_DICT 重载时的键名冲突，真实训练未启动。使用按参数名保存的 SHARDED_STATE_DICT 修复后，180648 的四 rank 小模型预检通过，再从共同初始权重重放一次真实更新。两次真实 step 分属独立进程，最终持久化的训练步数为 1。复跑复用了 180554 的轨迹和 180621 的判分。
